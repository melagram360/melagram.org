# Melagram.org Homepage

Luxury purple, gold, black, and cream homepage for Melagram.

## Stack
- Astro
- Tailwind CSS
- Cinzel + Inter
- Mobile-first responsive design

## Local development
```bash
npm install
npm run dev
```

The homepage is `src/pages/index.astro`.
The master Melagram logo is `public/images/melagram-logo.jpg`.
